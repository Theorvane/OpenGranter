# Bounded Gemini root schema identity

Issue #616, refs #116 and [plan552](552-ai-sdk-structured-output.md).

## Scope and design

Accept optional root-only $id as immutable metadata for explicit strict:false Gemini responseJsonSchema transport. The official GenerationConfig field lists $id (https://ai.google.dev/api/generate-content?hl=en); JSON Schema describes root identity and local reference resolution (https://json-schema.org/understanding-json-schema/structuring). This bounded subset accepts only canonical absolute HTTPS URLs up to 2048 characters with no credentials, query or fragment. Compare URL serialization without rewriting the captured schema. No network lookup, routing change, URI decoding, external references or nested base changes: every supported literal fragment still resolves only against root $defs. Root IDs on typed, union and reference roots are supported. Root/nested anchors, nested $id, unsupported reference siblings and cyclic/dangling references remain invalid. Existing depth16/shared20,000 visits/128 definitions bounds and IAM/limits/accounting/privacy stay unchanged. No output validation, live certification, pins/dependencies/storage or #561 changes. Full #116 and unresolved #7 remain open.
