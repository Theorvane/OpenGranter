# Management browser single-module build (#639)

1. Scope: build trusted TypeScript under src/management into the single public ESM string consumed by browser-http.javascript. This is executable UI delivery plumbing, not an authenticator, installed runtime activation, or a source sandbox. Frontend owns the app and entry; no default app is invented here.
2. Contract: an explicit entry is mandatory; resolve real paths inside src/management, reject bare packages, Node builtins and files outside that tree. Bundle transitive imports for ES2022 browsers, no source map, eval, file emission or external static imports. Do not inject process.env, credentials, tokens or session grants. Trusted source must itself contain no secrets or runtime code-loading constructs; esbuild metadata checks the resolved static import graph, not arbitrary JavaScript semantics.
3. Acceptance: actual boundary and catalog lifecycle modules execute after bundling; local TS imports are eliminated; output is deterministic. Missing entry, external dependency, path escape and symlink escape fail. CLI writes only JavaScript on success and a fixed failure on stderr otherwise.
4. TDD: run focused tests with the implementation absent (RED), implement, repeat GREEN, run typecheck/lint/scripts checks. Preserve exact-head CI and independent formal approval before merge.
5. Usage: npm run --silent management:build -- src/management/<reviewed-entry>.ts > /tmp/management-app.js. A trusted host supplies the resulting UTF-8 string to createManagementBrowserHandler/Server; no listener, auth or deployment is enabled by this build. Rebuild after source changes. Frontend entry, real SSO/IAM, browser integration, container installation and provider acceptance remain separate gates. Rollback removes the opt-in build command and files.
