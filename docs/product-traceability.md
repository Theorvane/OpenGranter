## Ordered next contracts

1. **R1 browser boundary:** choose same-origin server session/BFF versus deliberately designed OIDC client. Specify issuer/audience/keys, callback/redirect allowlists, state/nonce/PKCE, session lifetime/revocation, CSRF/CORS, ingress, no-store and errors before coding. Never put SSO/proxy secrets in URLs, browser persistence or logs. Define login/logout, expired-session, denial and current-principal tests.
2. **R2 management authority:** reuse fresh persisted evaluation and owner-scoped `iam:Manage` where applicable. Specify principal/role/policy CRUD, delegated scopes, concurrency and required atomic mutation audit. Simulator output does not authorize execution.
3. **R3 catalog/routing/limits:** separate discovery from mutation. Specify `catalog:Manage` resources, secret references, versioned prices, route kinds and budget/limit decisions before writes.
4. **R4 review:** reuse scoped reader/filter/CSV contracts through explicitly authorized browser boundary. Implement loading/error/denial/empty states. Content-audit policy remains a separate decision.
5. **R5/R6:** reconcile compatibility backlog, then installed browser/gateway/security/usage/restart acceptance using approved credentials/client/model and maximum paid budget. No automatic paid fallback.

R0 exit requires independent review and agreed contract ownership. This document alone does not close #638 or authorize unresolved security policy. See [plan](plans/638-product-traceability.md).
