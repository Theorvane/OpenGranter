# Name decision

The user selected **OpenGranter**. The name combines “Open” and “Grant” to convey authorized access to LLM resources. Use this spelling consistently in product documentation.

Avoid `OpenIAM` because an [existing IAM product](https://www.openiam.com/) uses that name. A quick web and GitHub search found no software with the exact name `OpenGranter`, but trademark, domain, and package-name availability still need separate checks before launch.

The current workspace path remains `openiam`. Use `opengranter` for product code and deployment names when implementation starts.
