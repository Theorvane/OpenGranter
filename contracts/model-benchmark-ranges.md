# Model discovery benchmark ranges

GET /api/v1/models supports min_intelligence_index, max_intelligence_index, min_coding_index, max_coding_index, min_agentic_index and max_agentic_index. Bounds are inclusive and conjunctive against the corresponding captured benchmarks.artificial_analysis number. Missing/null metadata cannot satisfy a selected bound. Zero remains known; negative scores remain valid metadata and retain existing unfiltered behavior.

Accept nonnegative finite decimal/scientific values with at most 128 UTF-16 units, no coefficient sign, whitespace or redundant leading zero. Use ordinary numeric score semantics, including finite underflow/rounding; these are not monetary values. Duplicate, empty, null-word, malformed, nonfinite, negative or reversed bounds reject after authentication and before catalog reads. Equal pairs are valid. Canonical numeric continuations retain every selected range and existing query field on a fixed relative path.

Complete catalog validation and enabled model/final-provider IAM precede all range matching, existing filters and sorting/paging. Each page reloads current policy/catalog. Hidden/disabled malformed metadata or required dependency/audit failure withholds the entire response privately. Source mutation during audit cannot change captured results; query/score values stay out of operational events/errors. Listing calls no inference, route, secret, limit or usage ports.

Legacy query rejection, omitted query order, other sorts and original metadata retain their behavior. Published scores may be inaccurate/stale and never establish provider choice or capability. Query pin v3 selects six official numeric/null parameter shapes and the fresh offset nullable:false marker alongside its unchanged integer/null type array. Removing these additions reconstructs v2 exactly; request/response pins do not change. Full #116 and unresolved #7 remain open.
