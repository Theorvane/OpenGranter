# Explicit canonical operations process

Run `node --experimental-strip-types scripts/start-canonical-operations.ts` only after approving the write-enabled selection. This executable imports the absolute `OPENGRANTER_BOOTSTRAP_MODULE` and requires its named `createCanonicalOperationsPorts` factory. A module containing only `createCanonicalReviewPorts`, `createSsoBrowserPorts` or `createGatewayPorts` fails closed. No existing script, container entry, environment default or installed service is switched.

The factory returns `openConnection`, `issuer`, `audience`, `jwks`, absolute `browserArtifactPath`, required lowercase 64-character `browserArtifactSha256`, and optionally the already-approved `migrationDirectory`. It must not contain private artifacts or credentials in JavaScript. Never put credentials in command arguments or shell history. Use the existing trusted deployment-module credential mechanism; no new credential loading path is introduced here.

`OPENGRANTER_HOST`, `OPENGRANTER_PORT` and `OPENGRANTER_SHUTDOWN_MS` retain the existing process configuration contract (loopback default). The process owns host, port, `Date.now` and random request IDs even if the trusted factory tries to supply replacements. Artifact validation and byte pinning precede DB acquisition. The existing operations bootstrap owns migrations, listener and connection cleanup. SIGTERM/SIGINT close once; startup and shutdown diagnostics never include module paths, SQL, JWTs or artifact contents.

The socket serves the public shell and canonical authenticated Account/Models/Usage/Audit plus existing token issue/revoke endpoints. Human signed bearer authentication, fresh IAM and mandatory durable audit remain authoritative. This is not a cookie session, SSO login flow, BFF, CORS grant or inference entry. No proxy credential is accepted as a management identity. Account audit DDL is still separately approved and installed, never automatically added by this process. See [bootstrap contract](canonical-operations-bootstrap.md).

Rollback selects the previous read-only executable and reviewed artifact/configuration; this does not undo completed token mutations. Do not replay timed-out mutations without reconciling their outcome. This change does not install, start persistently or deploy any service.

Evidence: process-unit tests reject alternate factories, incomplete pins and malformed configuration, enforce process-owned fields, close late startup runtimes and sanitize failures. A real loopback test with migrated PGlite and synthetic signed bearer exercises public bytes, private reads, CSV, issue/revoke/idempotence, fresh Deny, failed-audit transaction rollback and signal shutdown. CLI subprocess tests verify fixed errors for invalid configuration/missing trusted module. These do not certify actual browser login, native PostgreSQL, installed ingress/TLS or a live provider.
