# Model details links

Compatible rich discovery accepts credential-free absolute HTTPS links and root-relative links beginning with exactly one slash in links.details. Relative links retain their exact path/query/fragment spelling within the existing nonempty 2,048 UTF-16 unit limit. Reject relative authority/network paths, backslashes and raw whitespace/control characters (U+0000 through U+0020 and U+007F through U+009F), ordinary document-relative text, unsupported schemes and malformed absolute URLs. Existing absolute HTTPS behavior remains unchanged.

Validate relative links against a fixed synthetic HTTPS origin and require that origin to remain unchanged. Never derive the base from request Host/forwarding headers or fetch/follow/rewrite links. A detail link neither registers a route nor grants permission nor promises an implemented endpoint. The single-slash and character rules are local restrictions beyond the official string shape.

The shared metadata snapshot preserves text and freezes captured links before audit/database handoffs. Complete catalog validation includes hidden/disabled/out-of-page entries; malformed input and required dependency/audit failures fail privately. Existing enabled model/final-provider IAM, counts, pagination, legacy/basic payloads and private operational audit apply. PostgreSQL list/route boundaries share this validation and preserve approved routes. JSONB shape/64 KiB cap, migrations and all source pins remain unchanged.

Raw, installed OpenRouter/OpenAI SDK and persisted tests verify exact links, denials, failures, bounds and immutable capture. No link value reaches operational events/errors; listing calls no inference/route/secret/limit/usage ports. The referenced endpoint, metadata publication/refresh, complete external-client compatibility #116 and unresolved #7 remain open.
