# Delegated stream reasoning details

Both /v1 and /api/v1 preserve optional reasoning_details arrays on delegated text-stream deltas. Reuse the [nonstream subset](nonstream-reasoning-details.md): summary/text/encrypted variants, opaque nullable metadata, immutable scalar records and array snapshots, exact omission and empty-array behavior. Preserve frame and item order; do not merge indices, concatenate strings, decrypt payloads or certify signatures.

Reject null/malformed arrays, unknown keys/types and server-tool-call items with fixed safe failures. Validate at both upstream decoding and public SSE encoding. Any supplied details on usage-only events reject, including empty arrays and incomplete usage, before incomplete-usage early returns. This explicit local restriction prevents silent loss; never replay earlier details or fabricate final usage.

JSON framing protects embedded newlines. Authentication, model/final-provider IAM and explicit Deny, limits, required audit/ledger, cancellation/backpressure and failed-attempt billing uncertainty retain existing behavior. Pre-frame failures return safe JSON; later failures suppress terminal success and preserve safe interruption/accounting semantics. Detail payloads, signatures, IDs and credentials do not enter operational audit/ledger/error bodies. Missing usage remains unknown.

Acceptance cases cover actual pinned OpenAI/OpenRouter SDK sockets on both prefixes, exact array/null/omission/order behavior, malformed first/later frames, injected encoder bypasses, usage-only rejection with missing/complete counts, pre-dispatch denial/limits, required persistence failure and no content retention. Direct/tool streams, history replay, server tools, assembled reasoning history and native thinking remain open. Sources: [reasoning guide](https://openrouter.ai/docs/guides/best-practices/reasoning-tokens) and [streaming](https://openrouter.ai/docs/api_reference/streaming).
