# Compatible model counts

Authenticated GET /api/v1/models/count returns exactly {data:{count:N}} with no-store caching, where N is the number of distinct enabled aliases with an approved candidate satisfying model AND final inference-provider IAM and the selected output filter. Count aliases, not routes/candidates/providers. No user can infer inaccessible catalog totals. Every request reevaluates current state; zero is a successful known count.

Only output_modalities is accepted, using existing bounded any-member/all syntax. Omission defaults to text for this endpoint; unknown/absent metadata cannot establish text output. Explicit all includes every authorized alias, including basic metadata. Existing GET /api/v1/models omitted-filter behavior remains unchanged, so compare totals with the same explicit filter. Duplicate/empty/malformed or other query keys reject after authentication but before catalog access. Unsupported methods, /v1/models/count and trailing-slash variants remain unavailable.

Share complete catalog validation, enabled model/final-provider IAM and frozen capture with listing. Hidden/disabled malformed metadata invalidates the entire result. Required sanitized models-counted audit completes before output and contains only current visible count and existing attribution. Query/metadata values do not enter operational events or errors. Shared denial/unavailable audit and safe compatible errors apply. Listing/counting invokes no routing, inference, secret, limit or usage ports, and audit-time source mutation cannot change the captured count.

Audit storage/history recognizes models-counted using the existing nonnegative safe-integer count projection. Persist only allowlisted fields, retain attribution and principal isolation, fail safely on invalid counts or required storage faults. No database migration is needed. Local IAM defines proxy-token visibility independently of the upstream management-key error example. Raw and installed OpenRouter SDK tests provide bounded count conformance; the separate [count schema contract](model-count-schema.md) adds structural drift detection without changing runtime behavior. Other model endpoints, full #116 and unresolved #7 remain open. Source: [official reference](https://openrouter.ai/docs/api/api-reference/models/get-total-count-of-available-models), checked 2026-10-18.
