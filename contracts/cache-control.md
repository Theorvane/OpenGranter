# Explicit prompt cache control contract

Issue #434. Plan: [434-cache-control](../docs/plans/434-cache-control.md).

Both /v1 and /api/v1 accept optional non-nullable cache_control={type:"ephemeral",ttl?:"5m"|"1h"} on delegated OpenRouter/managed Anthropic nonstream and streaming text/refusal/function requests. Capture/freeze the directive and its known own type/TTL once before credential awaits. Omission adds no directive or TTL default; preserve exact supplied 5m/1h. Null, malformed objects, non-record prototypes, extra keys, missing/other type and null/unknown TTL reject before routes/credentials. Future TTL strings are an explicit unsupported runtime subset despite the source SDK open enum; source coverage retains that extension. Throwing root/type/TTL getters produce existing fixed safe errors; mutation cannot affect prepared controls.

Native OpenAI/Gemini supplied directives reject before secrets. Do not substitute prompt_cache_key/options/retention or cachedContent resources. Native Anthropic's nullable extension is not enabled by this public non-nullable field. Keep its existing version header and administrator output cap; add no beta header or model-support assumption. Top-level automatic caching marks the upstream last eligible block/prefix; minimum lengths, cache availability and TTL pricing remain provider/model behavior. Omitted native TTL defaults to five minutes upstream; the gateway does not inject that default. Explicit block breakpoints, mixed TTLs, resource ownership and retention policy remain outside this subset.

Preserve complete authenticated model/final-provider IAM/Deny, approved fixed hosts, limits, route-kind fallback bounds, per-attempt usage, required audit/ledger before final delivery, safe possibly-billed failures and cancellation. Controls never enter operational metadata/errors or response echoes, cannot alter caller identity or prompt content and do not enable local content auditing. No hit/savings/billed-cost/usage is inferred. Native reported disjoint cache read/write counters still enter existing prompt aggregates once; categories do not manufacture missing usage or alter billing authority. Independent caller user, cache placement keys and arbitrary metadata stay separate.

Version 24 selects 29 request fields and 16 request/history definitions, adding only cache_control plus whole AnthropicCacheControlDirective/AnthropicCacheControlTtl. Traverse TTL enum/type/extension even with unchanged parent refs, track required/default/bounds/extra structure and ignore annotations. Removing those three selections reproduces version 23 canonically. Verify fresh canonical source/projection provenance and reject missing/malformed sources, stale versions and rehashed invalid exact maps. SDK fixtures certify captured requests and existing delivery/error controls, not live provider support, cache hits or cost savings. Unknown TTLs, broader/native cache mappings, full #116 and unresolved #7 remain open.
