# Internal attempt-start price capture

`UsageHandoff.resolveAttemptPrice` is an optional synchronous trusted-composition port. Its frozen content-free context identifies request, route kind, model alias, upstream model, selected candidate (null for a delegated provider set), attempt number and startedAt. The composer owns applicable immutable version/model/route selection and must not supply flat rates for non-flat pricing. This is not an HTTP option, provider response field, catalog CRUD or permission grant. Production configuration does not provide this port.

When usage recording is enabled, routing calls the port once after existing authorization/limits and selection audit, before each provider dispatch. Returned allowlisted fields are read once, validated and copied/frozen, so later source mutation cannot reprice that attempt. Missing/null prices retain unknown estimates. No credentials or prompt enter this port. Managed fallback captures each candidate separately; delegated prices must apply to the whole approved provider set when candidate is null.

A throwing/malformed configured resolver fails that dispatch with usage-unavailable and an accounting failure audit; no provider call, fallback or synthetic ledger row. The audit possiblyBilled flag is false for that undispatched attempt; response flags preserve earlier potentially billed attempts. Existing post-dispatch usage handoff failures remain conservatively possibly billed. Disabled recording skips price resolution. This does not activate pricing in gateway composition, implement catalog/effective-version policy, price streams outside these orchestrators, collect bills or settle budgets.
