# Anthropic cache-aware native usage

Issue: #418. Plan: [418-anthropic-cache-usage](../docs/plans/418-anthropic-cache-usage.md).

Native Anthropic cache creation/read counts are disjoint from input_tokens. Supported nonstream text/refusal/functions and text/function SSE normalize prompt as input+cache-creation+cache-read when all components are known safe nonnegative integers; total is normalized prompt+final output within safe bounds. Preserve zero. Project valid cache-read/cache-creation counters as prompt_tokens_details.cached_tokens/cache_write_tokens. Do not add these informational projected details to normalized aggregates again, or derive billed cost from them.

Both cache fields wholly absent preserve the historical bounded input/output-only mapping; this does not certify complete cache/billing reporting. When initial/nonstream cache reporting is present, any missing/null component makes prompt/total unavailable, any malformed or overflowing component/sum makes prompt invalid, and cache-only data cannot manufacture input. Preserve independently valid details, but no details alone create usage. Invalid prompt details never enter client groups. Partial/invalid/missing usage retains existing ledger classification and compatible omission rules; successful content remains successful when usage is unavailable.

Streaming captures initial input/cache values, replaces supplied nonnull input/cache values per message_delta, and retains prior values across omitted/null updates. Counts are cumulative, never summed across events. Latest output is required; initial estimates never replace missing final output. Complete valid aggregate usage and required ledger/audit handoffs govern final usage/DONE. Unsafe/malformed stream content remains a sanitized opened possibly-billed failure. Captures contain no unknown payloads and use immutable bounded scalar snapshots.

New attempt ledger records receive corrected aggregates once and retain actual provider identity; no category ledger fields or extra attempts are introduced. Historical records, pricing, cache request support/defaults, model/think settings, IAM, limits, fixed hosts, cancellation and operational privacy remain unchanged. Native TTL decomposition, modality/server-tool categories, billed reconciliation, live providers, full #116 and unresolved #7 remain open. Sources: [prompt caching](https://platform.claude.com/docs/en/build-with-claude/prompt-caching), [streaming](https://platform.claude.com/docs/en/build-with-claude/streaming), [SDK accumulator](https://raw.githubusercontent.com/anthropics/anthropic-sdk-typescript/main/src/lib/MessageStream.ts).
