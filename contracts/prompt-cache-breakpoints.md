# Explicit text cache breakpoint contract

Issue #442. Plan: [442-prompt-cache-breakpoints](../docs/plans/442-prompt-cache-breakpoints.md).

Both /v1 and /api/v1 accept optional nullable prompt_cache_breakpoint={mode:"explicit"} on text parts in system, developer, user, assistant and correlated tool-result history. Managed OpenAI and delegated OpenRouter preserve the complete marked message array, exact empty/whitespace/Unicode strings, order and boundaries in nonstream and text/refusal/function streams. Null/omission removes the marker locally; native null semantics are not asserted. Messages without a non-null marker retain existing literal text concatenation. Capture root, indices, type, text, marker and mode before credential awaits, with frozen fresh records. Raw internal arrays require a non-null marker and own canonical indices. Marked messages contain at most 128 parts under existing body bounds; this local bound is not an upstream write/lookup limit.

Reject malformed/extra/prototype marker objects, missing/unknown mode, TTL or other marker fields, sparse/rich/extra parts and markers on refusal or prediction parts. Simultaneous request-level cache_control and marked history rejects before routing because mixed-format precedence is unverified. Root prompt_cache_options remains independent; omission injects no explicit-only mode or TTL. Existing prediction/control/function-history restrictions remain enforced. Native Anthropic/Gemini reject marked histories before secrets; their exported message converters also reject arrays rather than flattening or inventing cache_control/cachedContent semantics. Null-only/unmarked client arrays retain prior native behavior.

Authentication, complete approved model/final-provider/host scope, IAM/Deny, limits, required audit/usage before final delivery, missing usage and possibly-billed failure/cancellation stay shared. Marker data and private text remain outside operational records/errors and synthetic response echoes. Opt-in Jev prompt disclosure joins exact text with the existing role labels and literal nullable content, excluding marker metadata and object coercion. No cache hit, prefix retention, cache usage, savings or provider-billed cost is inferred. Model support remains upstream and catalog eligibility is unchanged.
