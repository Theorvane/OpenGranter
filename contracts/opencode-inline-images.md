# OpenCode Inline Image Conformance

Issue: #470. Plan: [470-opencode-inline-images](../docs/plans/470-opencode-inline-images.md).

Pinned OpenCode 1.18.5 explicitly registers the fixture alias with text/image input and text output modalities. The isolated runner attaches a synthetic valid one-pixel PNG using a positional prompt followed by --file and the absolute temporary fixture path. OpenCode converts that local attachment to an omitted-detail inline image_url; the gateway never retrieves the path or any remote image.

Verify delegated OpenRouter and managed OpenAI/Anthropic/Gemini on /v1 and /api/v1. Require at least one image-bearing request per non-denial probe, exactly one unmodified fixture image on every captured request, including every upstream tool-result continuation. The image command supplies an explicit title to avoid an auxiliary title request satisfying image evidence. Existing non-image probes continue to allow auxiliary text calls with the same controls. OpenAI/OpenRouter receive the exact data URL, Anthropic the exact PNG base64 source and Gemini the exact inlineData MIME/payload. No explicit detail is inserted. Responses are fixed native SSE fixtures, not vision-model inference.

Six modes per route/base cover rendered final text, actual read of fixture.txt with complete correlated call/result replay, initial model Deny, initial provider Deny, fresh provider Deny after the tool call, and child-termination cancellation. Initial Deny precedes limits/secrets/upstream and records no usage. Follow-up Deny authenticates again and prevents another upstream/limit/secret/usage event. Successful requests each persist usage and audit; cancellation aborts native transport and records failed possibly-billed missing usage. Image bytes, paths, prompt/response/tool contents and credentials remain absent from operational metadata.

Retain isolated temporary Git/config/data/cache/state, explicit environment allowlist, disabled plugins/external skills/config/model fetch/autoupdate, --pure, exact fixture.txt read permission, all other tools/paths denied, one-MiB child output cap, thirty-second process deadline and five-second intentional termination. Explicit local attachment preprocessing is the client's own file handling; it does not grant a model-invoked read permission for fixture.png. Cleanup closes sockets and removes the temporary project even on failure.

Default CI covers config/image-assertion and real gateway socket regressions without an installed client. The explicit installed-client command adds 48 image probes (four registered route/provider combinations × two bases × six modes) to the existing fifty probes. --images-only selects the 48-image subset for reproduction; absence/version mismatch fails explicitly. Image assertions detect changed payload, added fields and dropped content rather than treating text success as image conformance.

Remaining gaps: live image/model capability, other image formats/sizes/versions, remote media, output images, supplied native detail, image/cache combinations, signed-Google image combinations, automatic discovery and general interactive retries/cancellation. Complete #116 remains open, #7 is unresolved, and all three structural pins remain unchanged.

Versioned sources: [CLI attachments](https://github.com/anomalyco/opencode/blob/v1.18.5/packages/opencode/src/cli/cmd/run.ts), [custom modalities](https://github.com/anomalyco/opencode/blob/v1.18.5/packages/opencode/src/provider/provider.ts), [local image normalization](https://github.com/anomalyco/opencode/blob/v1.18.5/packages/opencode/src/image/image.ts), [compatible image serialization](https://github.com/vercel/ai/blob/%40ai-sdk%2Fopenai-compatible%402.0.41/packages/openai-compatible/src/chat/convert-to-openai-compatible-chat-messages.ts).

Actual probes exposed a #452 regression: OpenCode sends X-Session-Id on inference/title calls and the gateway had globally converted it to a native-unsupported body field. The correction limits header-only fallback to delegated OpenRouter after approved route resolution. Selected malformed headers still reject before route lookup; explicit native body identifiers still fail before secrets. No client namespace trick, plugin, header stripping in the fixture or native session equivalent is used.
