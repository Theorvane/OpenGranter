# Explicit workspace SQL audit reads

Only an own enableAuditHistoryReads: true on the trusted workspace factory enables GET /management/v1/audit through its owned committed/autocommit connection. Omission, false and inherited values keep the previous route surface. An own nonboolean value fails configuration; enabled SQL mode and any own writeAuditHistoryAccess field conflict before opening SQL. No externally selected connection or new audit callback. Existing signed RFC9068 identity, fresh audit:Read IAM, metadata redaction and awaited durable access audit remain mandatory. Candidate access-audit schema is caller-reviewed/installed, never auto-migrated; absence/failure returns a private 503. Public assets grant no identity and legacy management services remain unchanged. No session, provider calls or deployment authorization.
