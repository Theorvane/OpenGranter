# Nonstream token probability contract

Issue #420. Plan: [420-nonstream-logprobs](../docs/plans/420-nonstream-logprobs.md).

Both /v1 and /api/v1 accept nullable optional logprobs boolean and top_logprobs safe integer 0..20 for nonstream managed OpenAI/delegated OpenRouter. Non-null top_logprobs requires logprobs=true, including zero. Null/omission omits native fields; false/zero retain exact values. All supplied non-null controls on streaming or native Anthropic/Gemini reject before secret lookup/transport. This subset does not guarantee per-model support.

Choice-level logprobs preserves absence/null or a deep immutable object with required nullable content and optional nullable refusal. Each dense group contains tokens with required string token, finite number logprob, nullable dense byte array (integer 0..255), and required dense top_logprobs list; alternatives require token/logprob/bytes. Reject unknown keys, missing fields, sparse arrays, nonfinite numbers, invalid bytes and local bound violations. Preserve empty/zero/Unicode and finite sentinel/positive values without arithmetic or invented byte correspondence. Bounds are 65536 tokens across groups, 20 alternatives/token, 16384 UTF-16 code units/string, 1024 elements/byte array and 1048576 combined code units/byte elements across groups/alternatives. Probabilities remain response content, never usage counters or operational audit/error payloads.

Text/refusal/functions retain existing finish/message behavior. Missing usage stays missing; required ledger and outcome audit handoffs still precede delivery. Malformed opened responses fail safely with one possibly-billed failed attempt; Deny/limits cannot trigger secrets or upstream. Source pin v20 selects these controls and whole token/group definitions; local runtime bounds remain separate from source structure. Streamed probabilities, native mappings, capability routing, complete source/client conformance and #116 remain open. Sources: [OpenRouter parameters](https://openrouter.ai/docs/api/reference/parameters), [OpenAPI](https://openrouter.ai/openapi.json), [OpenAI chat](https://platform.openai.com/docs/api-reference/chat/create).
