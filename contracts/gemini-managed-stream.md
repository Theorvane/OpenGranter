# Managed Gemini public text streaming

Add bounded native Gemini text SSE validation, an explicit registered Google streaming transport and generated managed text dispatch through both API bases and persisted direct/dual composition. Preserve exact approved version scope, stable response identity, native output caps, authentication, model/provider Deny, limits, required usage/audit and cancellable backpressure.

Native Gemini requires SSE JSON and a first-event exact modelVersion plus nonempty responseId bounded to 256 characters. Later present identity fields cannot change. The gateway supplies one created timestamp and projects only its approved alias. One candidate with index omitted/zero is accepted; plain text parts may have absent/false thought, with up to 128 parts per event. Thought signatures, function/rich parts and unsupported routing/content fields reject. Native STOP maps to stop, MAX_TOKENS to length, and supported empty-content SAFETY maps to content_filter; prompt SAFETY is allowed only as the first terminal response with no candidates. Other native finish/block variants remain unsupported.

A terminal event and clean fully framed EOF are mandatory; there is no native DONE sentinel. One subsequent identity-consistent usage-only event may replace final aggregate counters. Earlier usage snapshots are never added or used to fabricate final values. Missing totalTokenCount stays absent even when prompt/candidate counts exist. Present totals are preserved, including hidden thought counts. Invalid aggregate values stay unavailable. Metadata categories are not projected in this slice. Shared SSE framing bounds events to 1 MiB, callbacks are awaited and cancellation/errors are opened possibly-billed failures. Completion summaries never retain text.

The explicit Google text mode uses the fixed registered HTTPS model endpoint with :streamGenerateContent?alt=sse and x-goog-api-key, without placing the key in a URL. OpenAI and Anthropic named modes retain kind restrictions. Generated persisted direct/dual text dispatch captures registrations and ignores runtime invocation overrides. Existing managed IAM, limit, no-output-replay, usage/audit and final-frame controls apply. Native Google function streaming stays unsupported.

A client final aggregate usage frame is emitted only when all three counters are valid. Partial known counts remain in the ledger as partial with unknown total; missing/invalid usage does not create false client totals. Successful DONE still waits for required usage and audit even when no aggregate usage frame can be emitted. Controlled SDK fixtures do not certify a live provider or external application.
