# User model source schema drift contract

Version 1 selects official GET `/models/user`, operation `listModelsUser`, OpenAPI/document identity, complete inline query objects `offset`, `limit`, `output_modalities`, and `sort`, explicit operation security, and the HTTP 200 `application/json` schema. It selects exactly three whole definitions: `ModelsListResponse`, `ModelsListResponseData`, and `Model`. This records the root/array/item chain behind the stable `ModelsListResponse` reference. The existing model-response guard separately covers 21 metadata definitions referenced by `Model`; this selection does not traverse arbitrary references.

The reviewed security declaration is `[{"bearer":[]}]`. Capture requirement names and scope arrays literally, including names that resemble schema annotations. Valid declarations such as `[]`, `[{}]`, another scheme, or changed scopes report drift; missing or malformed explicit operation security fails privately and never inherits top-level security. The pin validator requires the reviewed bearer declaration. Security-scheme component bodies, account preferences, privacy/retention, regional eligibility and authentication error responses remain outside this selection.

Preserve parameter location, optional required flags, serialization controls and complete schema structure: nullability, ordered enums, defaults, bounds, formats, references, additional properties and extensions. The official sort enum includes values the local runtime does not support. Recording them does not enable them. Strip editorial schema annotations while preserving annotation-named schema properties and literal extension/default/enum data. Canonicalize object-key order, not structural arrays. Selected named parameters must occur exactly once as inline query objects, with valid nonempty schemas and no `content` or `$ref`; reject selected inherited parameters and malformed inherited lists. Unrelated inherited references and extra unselected parameters are outside detection.

Require exact pin envelope/projection/parameter/definition maps, the current version, fixed official URL, valid ISO date, lowercase canonical SHA-256 and canonical structural projection. Pin identity, response root and bearer security are fixed. Missing/malformed containers, empty selected schemas, referenced response objects, duplicate selected parameters and noncanonical rehashed maps fail with fixed content-free diagnostics. Hash integrity does not independently authenticate provenance or perform complete OpenAPI/JSON Schema semantic validation.

Offline `npm run compatibility:check` validates six pins without network access. Explicit `npm run compatibility:drift` validates every pin before one bounded fixed-host fetch with omitted credentials, no supplied headers, redirect rejection and safe time/body limits. Compute all six selected comparisons before emitting results. Report each subset independently and exit nonzero on drift, invalid data or unavailable source; never write pins or invoke inference. Invalid sixth pins prevent all fetching; invalid sixth source withholds all partial success output. Shared `Model` drift affects model-response, single-model and user-model results; shared list-root/array drift affects model-response and user-model results. Metadata changes solely inside existing unselected targets remain the model-response guard's responsibility.
