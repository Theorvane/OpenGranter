# Exact audit request browser transport

Optional requestId is a case-sensitive exact identifier with the existing server ASCII grammar and 256-character maximum. Invalid values fail before transport. Query, page projection and CSV revalidation share the same captured scalar filters. Principal, time, model and opaque decimal continuation remain intersected. A wrong-request row withholds the whole page/CSV, not a partial success.

No credential acquisition, UI/session activation, automatic pagination or download; host still invalidates on identity change. Local test request ports are not real IdP or native-browser evidence.
