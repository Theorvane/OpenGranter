Duplicates, malformed input lists/all/unknown/case/whitespace variants, unknown sort and invalid search reject400 before catalog reads. q has 1..256 Unicode code points, no outer whitespace or C0/C1 controls, preserves internal spaces/punctuation and uses literal substring comparison after locale-independent Unicode lowercasing. No regex/wildcard, accent folding or Unicode normalization is applied. These are bounded local semantics, not complete upstream query support. /v1 still rejects nonempty queries.

Validate the whole catalog and enabled model AND final-provider IAM first. Then all input/output/parameter/context/search conditions must hold. Input requires every requested member in the captured published array; no metadata/empty arrays cannot establish capability. Search alias and optional published name/canonical_slug only; basic aliases can match their alias. Never search upstream model/provider IDs, hidden aliases, descriptions or route labels. total_count contains only matching authorized aliases; no hidden match count is reported.

Sort matching authorized aliases before paging: newest uses published created descending; context-high-to-low uses captured primary context_length descending, known zero before unknown/null/absent context, and trusted catalog order for ties. Omitted sort preserves catalog order. Never use top-provider limits or invent context/creation/capability values. Sorting mutates only the filtered copy. Informational alias creation/context metadata may be stale and does not certify selected-provider capability or provider release freshness.

Without offset/limit, return the whole matching sorted sequence. Explicit paging retains existing defaults/bounds. Fixed relative continuations retain every accepted query field, including literal encoded search text; no caller-controlled destination is added. Each page authenticates and reevaluates current catalog/IAM; there is no snapshot/cursor consistency guarantee. Required sanitized audit precedes output; values/metadata stay out of operational events/errors. Listing calls no inference/route/secret/limit/usage ports. Captured metadata and response order/values survive audit-time source mutation.
