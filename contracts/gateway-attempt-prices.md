# Trusted gateway attempt pricing port

ChatHandlerPorts.resolveAttemptPrice optionally forwards the existing UsageHandoff resolver unchanged to managed and delegated JSON, text SSE and function SSE routing. PostgresChatHandlerPorts exposes the same optional port; existing direct/dual factories inherit and forward it. No gateway service/bootstrap/config installs it. The trusted caller still owns applicable immutable flat-token version selection; this is not a price store or selection policy.

Invocation remains after authentication, model/provider authorization, limits and required selection audit and before provider dispatch. Missing resolver/null means unknown estimated cost. Invalid or throwing configured resolution produces the existing usage-unavailable response and audit, without dispatch, fallback, ledger fabrication or SSE DONE. Previously emitted/billed attempts keep existing conservative failure semantics. Only usage storage/history/export contain the estimate, never the provider completion or SSE payload. Request bodies and discovery/provider metadata cannot configure or override the port. No new permission, authentication/session contract, retention, DDL, billing or budget authority.
