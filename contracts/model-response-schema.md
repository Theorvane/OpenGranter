# Model discovery response schema drift contract

A separate version-2 pin selects official GET /models (operationId getModels), OpenAPI/document identity and HTTP 200 application/json schema. It captures exactly 21 complete definitions reachable in the reviewed source: ModelsListResponse, ModelsListResponseData, Model, ModelAliasTarget, ModelArchitecture, InputModality, InstructType, OutputModality, ModelGroup, ModelBenchmarks, AABenchmarkEntry, DABenchmarkEntry, DefaultParameters, ModelLinks, PerRequestLimits, PublicPricing, PricingOverride, ModelReasoning, ReasoningEffort, Parameter and TopProviderInfo.

The response schema currently references ModelsListResponse; its required data/total_count/links and required nullable links.next, the array/item references and full Model definitions remain structural. Preserve whole required lists, nullable types, enum order, references, defaults, bounds, formats, additionalProperties and extensions. PublicPricing contains advertised strings, optional numeric discount and conditional overrides; selection never makes these billed prices. DefaultParameters has a nullable object with additionalProperties:false and six optional fields. PerRequestLimits officially uses number counters; local integer restrictions are not invented in this pin. ModelLinks.details is an unconstrained string in the source, not an invented HTTPS format. Full source InputModality includes video even though the local query subset does not. Optional alias targets, benchmark data, reasoning configuration and richer architecture/pricing fields are selected structurally but remain outside runtime implementation.

Strip editorial description/title/example/examples/externalDocs/$comment annotations while preserving annotation-named schema properties and literal default/const/enum/x-* extension data. Object-key order is canonicalized; structural arrays retain order. Unrelated endpoints, queries, response headers, other status/media types and unselected components remain outside detection. References are retained as strings. New/remote targets are never fetched or automatically expanded; changed references detect drift, but changes solely inside a future unselected target need explicit follow-up selection.

Require exact envelope and projection/definition maps, nonempty JSON schema objects, fixed pin operation/status/media/root reference, fixed official URL, valid ISO date and canonical SHA-256. Missing/malformed selected containers/definitions, referenced response objects, empty schemas, excessive depth, nonfinite data and invalid/rehashed malformed maps fail with fixed content-free errors. Integrity is structural normalization and digest checking, not complete JSON Schema semantic validation or a source signature. A correctly rehashed reviewed valid change is allowed; this check does not authenticate a recorded source hash independently.

Offline npm run compatibility:check validates selected pins without network. Explicit compatibility:drift validates all pins before one fixed official HTTPS download using shared credential omission, redirect rejection, time/body bounds and safe errors. Compute every comparison before any success output, report each subset independently, and fail nonzero on drift/invalid/unavailable data. Neither mode writes pins or invokes a model. Runtime responses, IAM, catalog, audit, secrets, limits and usage behavior remain unchanged.

Version 2 (#509) removes only seven legacy nullable:true markers: DefaultParameters frequency_penalty, presence_penalty, repetition_penalty, temperature and top_p, and TopProviderInfo context_length/max_completion_tokens. Preserve explicit number/null or integer/null type arrays and number double formats. Nullability remains part of the schema; no runtime metadata change follows. Restoring precisely the seven markers reproduces the complete v1 projection digest 825714729401e81ab4a6196b7a8ed6b76d89a32c09869d02a18e812276ced87b. Independent exact-shape tests and restored-marker/type drift cases prevent a broad nullable-key normalization from hiding future changes. Version 1 rejects, including a correctly rehashed historical pin.
